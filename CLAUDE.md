# Project: Annan AI Consulting Website

## Tech Stack
* Framework: Next.js (App Router)
* Styling: Tailwind CSS
* Language: TypeScript

## Business Context & Vision
* Core Offer: AI operational consulting and workflow orchestration.
* Target Audience: Custom Home Builders looking to optimize operations and save hours.
* Niche Focus: Custom Home Builders.
* Golden Rule 1: NO location ties. The reference site has location mentions (like Toronto and Tarion) tied to specific local case studies. The new landing page copy must be entirely location-agnostic to support global prospecting (including Canada and Europe).
* Golden Rule 2: NO heavy tech jargon. Keep platform names like 'n8n' out of the main feature copy. Frame the "Document Search System" not as a retail software product, but as a live example of the custom operations tech we build for clients.
* Reference Material: https://www.antekautomations.com/ (Use ONLY for understanding the SCAN framework and the specific builder pain points mentioned there).

## Design & Inspiration
* Aesthetic: Modern, high-authority tech consulting. Premium, clean typography, generous whitespace. Do NOT copy the Wix site's visual design.
